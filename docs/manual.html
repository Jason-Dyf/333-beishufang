一、30 秒上手

  1. 电脑：双击桌面「333背书房」快捷方式，或直接双击 333背书房（平板版）.html。
  2. 安卓手机 / 平板（推荐 APK）：把 333背书房.apk 传到设备 → 点开安装（首次会提示「允许安装未知来源应用」，允许即可）→ 桌面出现「333背书房」图标，点开就用，完全离线。
  3. 安卓 / 苹果（网页版）：把 333背书房（平板版）.html 存进设备 → 用 Chrome / Edge / Safari 打开 → 「添加到主屏幕」，以后像 App 一样点开。
  4. 完全离线可用；只有「语音识别抽查」需要联网（见第六节）。
别用微信内置浏览器打开。微信里点开经常拿不到麦克风、也容易丢文件权限，会出现「加载失败 / 找不到文件」。存到手机后用 Chrome 或 Edge 打开最稳。

三、每天怎么用（建议 40–60 分钟）

  • 早上 10 分钟：首页「今日任务」，按它算的数背 / 刷 / 复习。
  • 白天碎片：一页纸遮词自测，或闪卡过一遍。
  • 晚上 20 分钟：先刷「错题本」本章错题，再随机 60 题。
  • 睡前 10 分钟：听我背书抽查 2–3 题，背不出的第二天重点看。
  • 每周一次：模考——30 道选择限时 40 分钟，或整套大题。

规律：背完一定点「标记掌握」，1 / 3 / 7 / 15 天后首页会自动提醒复习。

四、刷题怎么刷

  • 题库：冬青 1200 / 丹丹 1000 / 凯程 / 真题整卷 / 模拟冲刺卷 / 外教法案。
  • 按章刷：进题库 → 选章 → 开刷，做完立刻看解析。
  • 随机 60 题：整库乱序，用来检验；随机组卷：自己勾章节和题量。
  • 错题本：按「科目 → 章」聚类，可只刷本章错题；做错的题自动进来。
  • 热力图：每章按正确率上色，点格子直接开刷。
  • 收藏 / 笔记：题目右上角 ★ 和 ✎，自动进「收藏」「笔记」。

五、真题与搜索

真题整卷：2024 / 2025 / 2026 各一套（30 选 + 2 论述 + 4 材料），外加洪哥八套、丹丹六套模拟卷。点「开刷这套单选」即可练，卷面题数与题库一致；原卷缺答案的题会标注「只能看题、不计分」。

搜索（顶部放大镜）：

  • 结果按「科目 → 章」分组，每组最多 12 条，多了会提示你缩小范围。
  • 优先显示标题命中的考点，不参考练习题和模拟题。
  • 命中真题的条目标红，点「看原题 ▸」直接跳到那套卷那道题。
  • 有「只搜教材」开关，可排除题册。

六、听我背书（老师抽查）

  1. 侧栏「🎙 听我背书」→ 选来源（混合 / 大纲考点 / 200 题 / 整卷大题）→「🎲 抽一题开始」。
  2. 三种背法任选：
    • 🎤 开始背（APK 里走安卓原生语音）：点一下先弹麦克风授权，同意后直接开始听、边背边出文字，背完点「✅ 我背完了」判分。APK 会自动选最能用的一条路：①系统语音识别服务 → ②系统语音弹窗（很多机器上能调出「讯飞语记 / 小爱」的识别界面）→ ③都调不出来时提示装「讯飞语记」，并可用「🎧 录音回放」或「✍️ 打字默写」。
    • 🎤 开始背（浏览器里）：只有 https 或 localhost 打开的页面才允许麦克风；双击 HTML 打开的是 file://，安卓 Chrome / Edge 会一律拒绝麦克风（浏览器安全限制，不是软件 bug）。这时点「⌨️ 用键盘说话」，用键盘上的 🎤 说话输入，或直接打字默写，判分完全一样。
    • 🎧 录音回放 / ✍️ 打字默写：APK 里录音可回放自评；打字默写任何环境都能用，一样判分。
  3. 背完点「✅ 我背完了」，给 0–100 分：≥85 很稳 / ≥70 基本会了 / ≥50 半熟 / ≥25 还生；打分 = 原文吻合 45% + 采分关键词覆盖 55%，并列「说到的采分点」「还差这些」和参考答案。
  4. 录音只存在本机、不上传；历史成绩本地保存，首页显示今日抽查数与平均分。

七、模考

  • 选择题模考：从选定题库随机抽 30 道（四本书都覆盖），限时 40 分钟，交卷看分数与逐题解析。
  • 大题模考：随机抽论述 / 材料题，按分值给自己估分。
  • 题库可选：全部 / 冬青 / 丹丹 / 凯程 / 真题 / 模拟卷 / 法案；也可直接用某套模拟卷当模考卷。
  • 中途切后台、刷新，倒计时和答题进度都不会丢。

  • 版本：📘 大纲背书版（1324 个考点）/ 🧪 冬青200题自测版（196 道大题）。
  • 🧭 框架图：一章的知识点摊成一张图——宽屏是横向脑图（章名 → 主题簇 → 考点），手机是竖向树；同一主体的「主线链」（太学 → 文翁兴学 → 察举制度…）按 ①②③ 排好，点「遮住顺序」可照 ? 复述；「⇄ 并列组」把 …的原则 / …的方法 摆在一起；点任意考点直接跳背书页。

  • 放大：右上 A− / A＋ 调整字号（80%–160%），小屏平板也看得清；三种形态的选择会被记住。
  • 打印时工具栏自动隐藏，框架图会展开成可读样式。

九点五、大题批改（新）

  • 题库：298 道大题——3 套真题的论述与材料（18）、14 套模拟卷（84）、冬青 200 题（196）。每题都拆好了评分采分点（平均 7.1 点）。也可以「＋ 自定义题目」自己录题。
  • 怎么写：打字、粘草稿都行；手机上可以拍照（配了百炼 Key 会自动转成文字）。
  • 怎么判：论述 = 观点 50% + 论证 50%；材料 = 原理采分点 50% + 结合材料 50%。观点看踩中几个采分点（术语错整点不给、只写小标题算半命中）；论证看分点数、每点厚度、有没有因果逻辑；材料看有没有把材料原句搬进来。
  • 给什么：分数与得分率、分部进度条、✅ 亮点与得分依据、❌ 扣分依据与还缺的点、体例提醒（没分点 / 四字小标题不够 / 没引原话 / 字数不够自动封顶）、📈 提升建议、参考答案；下方「相关知识点」点一下跳去搜索复习。
  • ⚡ 速练大题：不用写全文，一行一句「小标题：一句大意」即可；引擎按采分点匹配，告诉你估分、点到哪些、还缺哪些、小标题够不够四字。练的是「三秒列框架」。
  • 🤖 AI 精批（可选）：在「AI 接口设置」里填 DeepSeek 官方 / 阿里云百炼 / 自定义端点的 Key，点「AI 精批」让它结合参考答案逐点点评。Key 只存本机，不上传、不写进仓库；不填也能用，本地判分完全离线。
  • 记录：最近 60 次批改存在本机，点一条能回到那道题重新看。

十一、常见问题

Q　刷新后一片空白？
A　已修：刷新会自动恢复上次位置；真起不来时会显示「重新载入」按钮。若在微信里打开空白，改用 Chrome / Edge。

Q　点「开始背」没反应？
A　语音识别要 Chrome / Edge + 联网 + 麦克风授权（地址栏左边锁图标里允许）。微信内置浏览器拿不到麦克风，会自动引导你用打字或录音。

Q　选项显示「（此选项原卷扫描缺行）」？
A　原卷扫描缺行，宁可标注也不编造；答案与解析仍有效。

Q　2024 第 26 题没有答案？
A　原卷答案解析缺页，页面标了「暂无答案与解析」，其余完整。

Q　手机会不会横向溢出 / 卡？
A　已按 390 / 768 宽适配；单文件 15 MB，桌面实测加载约 0.35 秒，长列表分批渲染。
