# 333 教育综合背书房

一个纯静态、双击 `index.html` 就能离线使用的 333 考研复习站点（无需服务器、无需联网、数据存在本机浏览器）。

## 打开方式

- 双击 `index.html`（推荐 Edge / Chrome）。
- 手机/平板：用同目录的单文件版 **`333背书房-平板版.html`**（样式、题库、22 本原文全部内嵌，一个文件拷走即可离线使用）；也可以把整个 `kaoyan333-site` 文件夹拷到设备上打开 `index.html`。

## 平板 / 手机离线版

`333背书房-平板版.html`（约 14.4 MB，单文件、零外部依赖）：

- 双击即开，不联网也能用；拷到平板后用任意现代浏览器打开，建议「添加到主屏幕」当 App 用。
- 启动只解析题目与考点数据（约 4.6 MB，桌面实测 350 ms 可交互）；22 本教材原文（2.66 MB JSON）改为惰性加载，搜索或点出处时才解析对应那一本。
- 平板/手机性能优化：长列表 `content-visibility` 离屏跳过绘制、关闭毛玻璃与多层阴影、选项/按钮 `touch-action: manipulation`（去点击延迟）、`user-select:none`（长按不选中）、底部导航 72px 安全区。
- iPad：Safari 不允许直接打开本地 html，用 Documents by Readdle 这类支持本地文件的浏览器打开。
- 进度存在各设备自己的浏览器里（localStorage），电脑与平板不互通。

## 数据从哪来

全部由本机 PDF 经 OCR + 结构化整理而成：

- 丹丹《27 版大纲考点轻松记》255 页 → 考点（`assets/data/parts/*.js`）
- 冬青《333 主观题 200 题》304 页 → 主观题卡片（`assets/data/q200parts/*.js`）
- 冬青《材料题 70 个考点精讲》49 页 → 材料题考点（`assets/data/m70parts/*.js`）
- 冬青《选择题 1200 题》题目册 263 页 + 解析册 312 页 → 选择题（`assets/data/quizparts/qz-*.js`）
- 丹丹《1000 题》题本（教原 76 / 中教 54 / 外教 48 / 教心 32 页）+ 解析册 334 页 → 选择题（`assets/data/quizparts/dz-*.js`）
- 2024/2025/2026 整卷 → `assets/data/zhenti-papers.js` + `assets/data/quizparts/zt-papers.js`（文字层或 OCR，带答案解析）
- 洪哥八套卷 + 丹丹六套卷 14 套模拟卷 → `assets/data/mock-papers.js`（OCR 后结构化，单选 398 道）
- 四大纲全解（中教 216 / 外教 222 / 教原 213 / 教心 152 页）→ 原文库（`assets/data/src/s-dagang_*.js`）
- 凯程《333 应试题库》试题册 183 页 + 解析册 304 页、冬青《选择题考点清单》162 页、丹丹《1000 题》8 册 → 原文库（用于检索与验题）
- 《外教史 59 个法案记忆表格》→ 法案表（`assets/data/bills.js`）

原文库、出处索引在 `assets/data/src/` 与 `assets/data/pointsrc.js`；题目→原页映射在 `assets/data/qsrc.js`（2135 道题中 1581 道能定位到原页）。原文按需加载，首屏只加载 5 本核心书目。

## 使用小贴士

- 网址后面加 `#<视图>` 可直达：`#quiz`、`#quizrun`、`#q200`、`#bills`、`#recite`、`#srch`、`#method`、`#scoretips`、`#zhenti`、`#onepage`、`#quizmock`。
- 网址加 `?theme=dark` 可强制深色（如 `index.html?theme=dark#quiz`）；右上角 🌙 切换并记住。
- 深链：`#recite/ep-01` 直接展开某一章；`#srch/dagang_cn/144` 直接看某本书某一页；`#srch/癸卯学制` 直接搜；`#zhenti/2025/c` 直接看某套卷的选择题。
- 背书页每个考点右侧的蓝色小标签＝出处，点它会跳到「教材原文」并定位到那一页。
- 刷题设置里可开「刷对才算过」「答对自动跳」「隐藏出处」；数据存在浏览器本地，换设备不同步。
- 想重置：刷题设置 → 重置全部；或浏览器清站点数据。
